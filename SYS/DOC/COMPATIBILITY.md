# Compatibility

## Compatible Software

### Big Five Games

Appear to be able to save hiscores to disk.
Games that have a loader screen, also check for
existence of floppy disk and a patch needs to be installed to
bypass this

````
Search For : 
3A EC 37 CB 4F 20
Replace With :
3A EC 37 CB 4F 18

Search For :
3A EC 37 CB 4F C8
Replace With :
3A EC 37 CB 4F C9
````

### Visicalc

Appears to be able to load and save files to disk.
